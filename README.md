# Spotify UI

Ejercicio de maquetación frontend: réplica de la interfaz de un reproductor de música, construida con HTML, CSS y JavaScript sin frameworks.

## Contenido

- index.html — pantalla principal del reproductor
- inicio.html — pantalla de inicio
- login.html — pantalla de autenticación
- styles/ — hojas de estilo
- img/ — recursos gráficos
- aud/ — archivos de audio de ejemplo

## Objetivo

Practicar maquetación con CSS (flexbox, grid), posicionamiento y estilos de componentes, replicando una interfaz real a partir de su diseño visual.

## Ejecución

Abrir index.html directamente en el navegador, o servir la carpeta:

    python -m http.server 8000

Luego abrir http://localhost:8000

El proyecto está desplegado con GitHub Pages.
